# Responsiveness & Optimization

## Device Support

- Must work on mobile, tablet, and desktop
- Mobile-first design approach
- No fixed widths
- Use responsive Tailwind utilities

## Layout Rules

- Use responsive grids and flex
- Avoid horizontal scrolling
- Tables must be scrollable on mobile
- Sidebars collapse on small screens

## Performance

- Minimize re-renders
- Avoid heavy components on initial load
- Lazy load charts, maps, and modals

## Touch UX (Mobile)

- Buttons must be touch-friendly
- Minimum tap size: 44px
- Avoid hover-only interactions
