# Asset Rules

Images:

- Use high-quality vehicle images
- Aspect ratio: 4:3
- Always include alt text

Icons:

- Huge Icons only
- No custom SVGs unless approved

Illustrations:

- Used only for empty states
- Minimal, outline style

File Naming:

- kebab-case
- role-context prefix
  example: user-empty-bookings.svg

Upload Limits:

- Max image size: 5MB
- Accepted: jpg, png, webp
