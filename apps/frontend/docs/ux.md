# UX Rules

Navigation:
- Sticky top navbar
- Sidebar for dashboards
- Breadcrumbs for deep pages

Feedback:
- Skeleton loaders for data
- Button spinners for actions
- Toasts for success/error

Empty States:
- Illustration
- Explanation text
- CTA button

Errors:
- Friendly copy
- Never expose raw API errors

Transitions:
- Page fade-in
- Modal slide-down
- Button hover scale 1.02
