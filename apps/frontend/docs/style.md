# Design System – Vehicle Rental Management System

## Brand Inspiration
- Inspired by SIXT
- Premium, bold, minimal, high-contrast

## Colors (DO NOT CHANGE)
Primary:
- Orange: #FF5F00

Backgrounds:
- Dark: #000000 – #1A1A1A
- Light: #FFFFFF
- Muted: #F5F5F5

Text:
- Primary: #000000
- Secondary: #666666
- Muted: #999999

Status:
- Success: #28A745
- Warning: #FFC107
- Error: #DC3545
- Info: #17A2B8

## Typography
Font:
- Inter (fallback: system-ui)

Sizes:
- H1: 48px
- H2: 36px
- H3: 24px
- Body: 14–16px
- Button: 14–16px semi-bold

## Layout Rules
- Mobile-first
- Max content width: 1280px
- Sidebar width: 260px
- Border radius: 6–8px
- Shadow: 0 2px 8px rgba(0,0,0,0.1)

## Buttons
Primary:
- bg-orange-500
- text-white
- hover: darken 10%

Secondary:
- border-orange-500
- text-orange-500
- hover: fill orange

Danger:
- red theme
- used only for destructive actions

## Cards
- bg-white
- rounded-lg
- shadow-sm
- padding: 20–24px

## Forms
- Input height: 48px
- Border radius: 6px
- Focus ring: orange
- Error text below input

## Accessibility
- WCAG 2.1 AA
- Keyboard navigable
- Focus visible on all inputs
